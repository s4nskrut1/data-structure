## A closer look

### Searching

The repository includes implementations of fundamental searching techniques. For example, `1.1.1` implements **linear search**, reading an array, accepting a key, and reporting its position when found.

### Practical implementations

The numbered files represent the progression of the original laboratory work. Keeping the original filenames makes it easier to match each implementation with the corresponding practical or submission.

### C programming

All implementations are written in **C**, keeping the focus on understanding the underlying logic rather than relying on high-level abstractions.
